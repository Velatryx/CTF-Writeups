Bulk Import

This endpoint accepts a batch manifest produced by Bulk Export and restores it against the live database. It is used exclusively by the legacy migration tool during the vendor cutover and is not intended for browser use.

Batches are base64-encoded, serialised manifest objects, POSTed directly as the request body to this same URL.

Example (migration tool CLI)

migrate-tool export --batch legacy-2019 | migrate-tool push http://ironhold-internal:8080/admin/import
